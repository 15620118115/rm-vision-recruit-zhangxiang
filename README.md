\### 问答题

1\. \*\*内参矩阵中各参数的物理含义是什么？fx 与 fy 为何接近？\*\*

fx、fy分别是x方向、y方向的等效焦距，单位为像素；cx、cy是镜头光轴与成像平面交点的像素坐标（主点坐标）。

普通摄像头传感器的单个像素为正方形，x和y方向像素尺寸一致，因此fx与fy数值接近。



2\. \*\*重投影误差衡量的是什么？\*\*

重投影误差是将三维世界坐标点通过标定得到的相机模型，重新投影到二维图像平面，计算投影像素点与实际检测像素点之间的平均偏差，单位为像素。它用来衡量相机标定结果的精度，误差越小说明标定模型越准确。
